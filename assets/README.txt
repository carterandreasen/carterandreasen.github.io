This folder is where your personal files go:

- resume.pdf     → your resume, linked from the sidebar's "Resume" button
                    on every page.
- profile.jpg     → optional profile photo, if you want to add one to
                    the homepage (see the commented-out example in
                    index.html's hero section).

Git doesn't track empty folders, so this text file exists just to keep
the "assets" folder in your repository until you add real files to it.
Delete this file once you've added your own.
